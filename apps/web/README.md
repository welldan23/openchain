# web

Frontend OpenChain Intelligence (Next.js 16, App Router). Lihat README di root
repo untuk cara menjalankan.

Data halaman Token sementara berasal dari `src/lib/mock`, diakses lewat
`src/lib/api/tokens.ts`. Saat backend siap, cukup ganti isi fungsi di file itu
dengan pemanggilan API. Bentuk datanya mengikuti `src/lib/types.ts`.
